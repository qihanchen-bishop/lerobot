\subsection{Visual Completion and Milestone Review}
固定前视相机作为日常任务的主要评价视角，侧视用于辅助人工审核遮挡或边界不清的情形。
完整目标区域由独立参考轮廓定义，不使用被目标遮挡后的可见区域分割代替。
目标暂时不可见时，不以可见掩码为空推断完整入区；无法可靠判断的时段不计为已确认成功。
完成时目标须仍位于区域内，曾经入区后又被拨出不计为成功。

\subsection{Trial Allocation and Accounting}
示范初始位置为$(0,0)$、$(0,3)$、$(1,1)$、$(1,2)$、$(2,0)$和$(2,3)$，
基础测试覆盖全部12个网格位置与三类已见物体的组合，扩展测试使用未见颜色的布料。
各方法使用相同的物体--位置--颜色组合和初始布置规则，
逐试验记录物体、位置、布料颜色、checkpoint、训练种子、执行重复、完成时间和主要失败原因。
总体结果与分组结果使用同一组试验，逐位置结果保留分母。
整体成功率为完整测试池中的成功次数除以试验总数，不对相互重叠的分组列求和。
位置与颜色分组比较匹配其余条件，区分未见位置、未见颜色及两者同时变化的组合。
测试前冻结策略与分割模型，并核对未见位置和颜色是否出现在分割开发数据中。
\draftnote{填写未见颜色、扩展测试组合及各组分母；
若分割开发已使用这些条件，明确其仅对策略示范未见。
更换颜色时尽量保持布料材质、尺寸及厚度一致。}
关键比较使用多个独立训练种子，区间估计保留训练种子与条件区组结构；
同一checkpoint的执行重复不代替训练重复。
每次试验记录一个主要失败类型，过程异常可另加标签，但不重复计入主要失败分布。
\draftnote{核对示范的物体--位置清单与各条件样本数；
补充实际重复次数、训练种子、区间估计方法、网格间距及布料／物体朝向重置规则。
基础测试数为36乘以每个条件重复次数，扩展测试按预先固定的组合清单另计；
消融沿用基础测试时与包含扩展条件的整体结果分开报告。
预先规定超时、安全停止、技术故障的统计与重试方式，保留全部尝试记录。
失败分类优先采用可审核的未完成里程碑或现象，不将推测的模型原因当作评价标签。}

\subsection{Natural Error and Recovery Review}
\label{app:naturalrecovery}
从各组全部执行视频与日志中识别自然错误，不仅抽取成功恢复的片段。
预先固定下列可观察条件，按任务阶段解释运动与进展，不以模型自身的预测判定恢复：
\begin{itemize}
\item 布料缠阻：布料卷入或持续阻碍工具／目标运动；解除阻碍并恢复当前操作进展时记为恢复。
\item 无效接触：工具完成面向目标的推动动作而未建立有效接触或产生目标进展；随后有效接触并推动目标时记为恢复。
\item 输送偏差：目标被推离通往区域的操作路径或停在区域边缘未完整入区；重新建立朝向区域的有效输送时记为恢复，完整入区另记为里程碑。
\item 执行停滞：尚未完成任务时，在预定持续时间内无有效进展；重新产生当前阶段的有效进展时记为恢复。
\end{itemize}
错误事件从首次满足判据时开始，到恢复、任务终止或预定恢复窗口结束时结束。
窗口须有完整随访时间且恢复须持续达到确认时长；窗口内任务终止且未恢复的事件记为未恢复。
同一连续事件不逐帧重复计数，只有完成恢复后再次出错才记录新事件。
重叠现象采用一个主要事件类别，其他现象保留为辅助标签；
持续输送偏差继而停滞等连续过程不拆成多个独立恢复机会。
发生至少一次错误的试验计入错误发生率；恢复耗时仅在已恢复事件上计算，
同时报告恢复数／事件数及出错试验的最终成功数／试验数。
无事件时恢复率不适用；不可审核事件单列数量，不静默剔除。
\draftnote{确定各阶段的有效进展判据、位移／接触容差、停滞时长、恢复窗口、确认时长及事件分类优先级。
按物体、位置与错误类型报告样本量，必要时按严重程度分组；区间估计以试验为聚类单位。
无法进行完整随访且未终止的事件单独报告。选取典型恢复、未恢复与有害修正片段，避免只展示成功案例。}

\subsection{Representation Diagnostics}
\label{app:evaluationdiagnostics}
专家动作重构探针比较三种输入：上下文、审核描述量加上下文、预测描述量加上下文。
使用容量匹配的小型读出模型和相同动作目标，训练与评价按完整轨迹分开；
上下文的内容保持一致，不包含待预测专家动作或其未来观测。
评价集同时记录描述量误差、标签有效比例和动作重构误差。
该探针检验任务信息与动作选择的联系，不能替代部署侧专家标注，
也不直接估计覆盖常数或条件误差差异。
\draftnote{填写上下文、动作尺度、读出模型和独立评价轨迹。
若历史模型使用速度或上一指令，列明其数据来源与时间范围，确保比较不引入未来信息。}
