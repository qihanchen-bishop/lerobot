\subsubsection{Perception and Task Information}
质量筛选针对视频中的异常变化，不能排除时间上稳定的系统性误分。
所选描述量刻画对象属性与空间关系，但不一定足以解释接触状态或专家的具体动作选择；
语义分割准确与描述量读出准确也不意味着策略已经正确利用这些信息。
\draftnote{结合图~\ref{fig:failurecases}(a,b)区分分割错误、描述量估计错误和执行决策错误。
说明是否存在描述量准确仍失败的情况，并联系理论中的专家选择近似误差解释未被当前信息覆盖的动作选择因素。
没有探针或干预证据时，将原因表述为待验证解释，而非确定归因。}

\subsubsection{Residual Prediction and Execution}
历史提供新的动作--响应证据，但有限数据、修正幅度和执行延迟可能限制其作用。
依据第~\ref{sec:feedbackanalysis}节，实际收益取决于可预测误差与残差实现误差的关系，
而不是仅由是否使用GRU决定。
\draftnote{结合图~\ref{fig:failurecases}(c)和表~\ref{tab:recoveryruntime}区分预测不准、
时效不足、修正过大和超出可恢复范围的案例；比较MLP与GRU在哪些条件下出现不同结果。
修正之后发生失败仅说明时间关联，若无匹配对照，不直接声称由残差造成。}

\subsubsection{Scope of the Evidence}
本文的任务表现界使用总体模仿误差，并依赖覆盖、动作敏感性和专家选择条件。
独立轨迹上的读出和动作误差用于检验相应机制，
不能将有限训练损失直接代入这些界，也不能据更紧的上界确定实际成功率排序。
两个任务上的分别训练验证方法的适用性，不等同于零样本跨任务迁移；
手术模拟材料上的实验亦不构成临床有效性证据。
\draftnote{根据真实划分与训练重复说明结论覆盖哪些物体、位置和平台。
联系理论B--D总结哪些机制获得实验支持、哪些条件尚未得到直接测量；
概括新增任务的描述量设计、语义标注与训练成本。
若未做多预算实验，不声明样本效率优势；QToken没有独立停止头时，不将任务成功等同于自主停止能力。}
