\begin{abstract}
本文研究在有限示范条件下，如何通过语义引导的任务关系表示与历史条件反馈，
改善动作块模仿策略的任务完成表现。
研究针对两个互补缺口：有限动作监督未必充分保留任务相关关系，
而生成动作块时的观察也未必足以解释执行期间的动态变化。
为此，基础策略结合语义输入与几何监督查询生成动作块，
历史条件残差分支利用新观测和当前计划修正尚未执行的目标槽位。
条件性分析分别刻画表示误差、历史增量信息与实际修正收益，
并说明动作风险改善转化为任务表现改善所需的覆盖、敏感性及时间对齐条件。
实验设计通过表示与反馈交叉对照、示范规模比较及机制诊断检验上述路径。

\end{abstract}
