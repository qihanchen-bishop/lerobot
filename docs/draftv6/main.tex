\begin{abstract}
视觉模仿学习在动态交互中既需要提取任务相关信息，也需要响应执行期间的新变化。
本文研究语义监督、几何查询表示和历史条件反馈改善任务表现的条件。
首先，在共同任务完成目标下分析模仿误差、分布覆盖与任务敏感性的关系；
随后讨论确定性语义作为归纳偏置的作用，以及历史残差降低动作风险所需的信息和拟合条件。
基于这些分析，构建语义增强动作块策略与历史条件残差反馈框架。

\end{abstract}
