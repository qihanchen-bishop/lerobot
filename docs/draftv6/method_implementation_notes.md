# Method 定稿核对

本文件为内部编辑与实现记录，不属于论文正文或附录。依据改写前的 `method_details.tex` 整理；本次未重新审计代码或运行训练，不能据此认定以下待办已完成。

## 数据独立性

- 现有分割开发记录采用质量筛选后的帧级随机划分；跨视频评价需要独立的视频级清单。
- 种子参与了初始教师训练，后续可用于开发参考，不作为独立最终测试。
- 已有残差缓存记录任务分层的训练/验证划分，但基础策略可能见过所有轨迹；原始 episode 名单仍需核对。已有 `data_split_audit.json` 保留了证据范围与缺失项。
- 最终实验需统一标注、分割、基础策略与残差各阶段的数据用途，不能把残差头验证等同于全流程未见数据验证。

## 质量监督

- 迭代分割已记录种子退出后续拟合、扩展样本跨轮累积和模型重新初始化。
- 旧 Qtoken-FS 使用早期启发式质量分数与连续软加权，未接入新版整段视频质量状态。
- 描述量相关证据聚合、硬异常排除及经人工审核校准的降权需实现并验证，不能将旧 checkpoint 视为已采用这些步骤。
- 旧面积监督将空目标掩码视为零面积；新版需区分确认不可见、漏分与标注失败。
- 校准证据不足时采用准入门控；连续降权另行消融。组内权重归一化主要调整相对贡献，不保证统一降权会降低整组损失。
- 温度校准和扰动集成不属于当前方法，已去掉附录中将它们列为必做模块的矛盾表述。

## 表示与残差

- 任务描述量仍由 front 掩码生成。工具几何左端点不必等于物理接触端，区域质心距离不等于物体完全入区。
- 查询精度与缓存均在 ACT 部署模式下评价；不要用受示范动作后验影响的训练读出误差替代。
- 保持基础与残差使用同一动作监督来源和尺度。当前完整反馈记录的观测为 follower 状态，监督为 leader 指令，不在论文编辑中暗改动作目标。
- Smooth L1 加残差正则是实际训练目标；理论中的条件均值和收益恒等式对应平方误差，需独立报告同尺度的 MSE。
- 离线回放不模拟残差执行后的环境变化；新方法的收益须通过匹配闭环测试验证。
- 时效验证需要真实时间戳，不能把目标频率或纯网络耗时当作实际反馈频率或端到端延迟。

## 定稿取舍

论文保留监督定义、数据独立性、描述量几何约定和目标动作对齐。颜色数值、网络尺寸、优化器参数、具体阈值及调度舍入规则由最终代码与配置提供，不再全部收入附录。代码尚未公开时不写成“已开源”。
