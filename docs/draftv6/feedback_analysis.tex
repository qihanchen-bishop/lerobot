% D主线：剩余动作误差 -> 新信息的可预测性收益 -> 学得残差与任务界。
\subsection{Information-Conditioned Residual Corrections}
\label{sec:feedbackanalysis}
% C给出保留专家选择依据的条件，但信息保留不自动消除实际动作误差。
Section~\ref{sec:representationanalysis} identifies conditions for preserving information needed to reconstruct expert actions.
Such preservation does not eliminate the learned policy's imitation error, particularly when actions rely on outdated observations or limited execution history.
% 本节分析额外信息何时使剩余误差更可预测，以及学得残差何时实现这一收益。
We examine when additional observations and history make the remaining error more predictable, and when learned corrections realize this potential to reduce $R_\nu$.

% \subsubsection{剩余动作误差的预测}
\subsubsection{Residual Prediction of Action Error}
% 固定基础动作，将残差学习表述为对剩余专家动作偏差的预测。
We treat residual learning as prediction of the action deviation left by a fixed base policy.
% 所有比较使用相同的总体分布、专家目标、执行时刻与动作尺度。
All comparisons use the same demonstration distribution $\nu$, expert targets, target execution steps, and action scale.
% 使用大写E表示向量误差，避免与B3中的标量距离e(h)混淆。
For base policy $\pi_{\mathrm b}$, let $B=\pi_{\mathrm b}(\mathcal H_t)$ and define the residual target
\begin{equation}
 E=\pi_{\mathrm E}(\mathcal H_t)-B.
 \label{eq:residualtarget}
\end{equation}
% 三种信息均为当前决策之前可获得历史的子集；基础动作可由最小信息集合确定。
Let $\mathcal F_{\mathrm b}\subseteq\mathcal F_{\mathrm c}\subseteq\mathcal F_{\mathrm h}\subseteq\sigma(t,\mathcal H_t)$ denote the information used to generate $B$, its augmentation with updated observations, and its further augmentation with execution history.
The base action is $\mathcal F_{\mathrm b}$-measurable; all added information is available before the target action is executed.
% 在有限二阶矩下，条件均值是给定信息能够预测的误差部分。
For any such information $\mathcal F$ and $\E_\nu\norm E^2<\infty$, the ideal residual predictor and its minimum squared error are
\begin{align}
 r_{\mathcal F}^*&=\E_\nu[E\mid\mathcal F],\nonumber\\
 R_\nu^*(\mathcal F)&=\E_\nu\norm{E-r_{\mathcal F}^*}^2.
 \label{eq:optimalresidual}
\end{align}
% 这是不限制模型形式的预测基准，不预设动作可行性或可学习性。
This is an unrestricted square-integrable prediction benchmark, not an assumption that a network attains it or that $B+r_{\mathcal F}^*$ satisfies all action constraints.
The derivation is in Appendix~\ref{app:optimalresidual}.

% \subsubsection{额外信息的预测价值}
\subsubsection{Predictive Value of Additional Information}
% 额外信息只有改变了对误差的最佳预测，才有严格的潜在收益。
Additional information has strict predictive value when it changes the best estimate of the remaining action error.
% 同一基础策略和评价分布下，嵌套信息对应的最优误差之差为预测变化的平方。
For $\mathcal F_0\subseteq\mathcal F_1$,
\begin{equation}
 R_\nu^*(\mathcal F_0)-R_\nu^*(\mathcal F_1)
 =\E_\nu\norm{r_{\mathcal F_1}^*-r_{\mathcal F_0}^*}^2.
 \label{eq:residualinformationgain}
\end{equation}
% 分别比较基础与当前、当前与历史，可分离更新观测和历史的潜在贡献。
Applying this identity to $(\mathcal F_{\mathrm b},\mathcal F_{\mathrm c})$ and $(\mathcal F_{\mathrm c},\mathcal F_{\mathrm h})$ separates the potential contributions of updated observations and history.
% 新信息若不改变条件均值，潜在收益为零。
The gain is zero if the conditional mean is unchanged; more information alone does not imply a strict improvement.
% 证明见对应附录，收益针对理想预测而非具体历史网络。
Appendix~\ref{app:residualinformationgain} gives the proof.
These gains concern optimal prediction, not the performance of a particular history model.

% \subsubsection{实际修正与任务表现界}
\subsubsection{Realized Corrections and Task-Performance Bounds}
% 实际收益取决于可预测误差是否超过残差模型自身的预测误差。
A learned correction improves imitation accuracy only when its prediction error is smaller than the error that the available information makes correctable.
% 实際残差是信息F的函数；定义相对理想预测的误差，不把它与训练损失等同。
Let $r_{\mathcal F}$ be the square-integrable, $\mathcal F$-measurable residual actually applied, and let $\pi_{\mathcal F}(\mathcal H_t)=B+r_{\mathcal F}$.
Define $\epsilon_{\mathrm{res}}(\mathcal F)=\E_\nu\norm{r_{\mathcal F}-r_{\mathcal F}^*}^2$.
Then
\begin{equation}
 R_\nu(\pi_{\mathcal F})
 =R_\nu(\pi_{\mathrm b})
  -\E_\nu\norm{r_{\mathcal F}^*}^2
  +\epsilon_{\mathrm{res}}(\mathcal F).
 \label{eq:realizedresidualrisk}
\end{equation}
% 因而可预测部分大于实际预测误差时才降低总体模仿误差。
Thus, $R_\nu$ decreases if $\epsilon_{\mathrm{res}}(\mathcal F)<\E_\nu\norm{r_{\mathcal F}^*}^2$.
% 该误差包含模型限制、学习不足与动作后处理；信息收益可能被学习误差抵消。
The realization error includes model limitations, imperfect learning, and output constraints.
Richer information improves the learned correction only if its predictive gain exceeds any increase in this error (Appendix~\ref{app:realizedresidual}).

% 返回B3：纠偏不改变A4的要求，降低总体动作误差只是收紧任务界的一条路径。
For admissible corrected actions, the task-performance implication follows from~\eqref{eq:representationcoveragebound} under its coverage and action-sensitivity conditions.
% 纠偏可能改变部署分布，因此评价完整组合项，而不是假定C和D不变。
Corrections may change the deployment distribution, so the relevant quantity remains $C_\phi R_\nu(\pi)+D_\phi$ for each complete policy.
% 在共同外部条件下，组合项减小收紧界，但不证明实际成功率排序。
For a fixed expert baseline, horizon, and positive action-sensitivity bound, reducing this combined quantity tightens the task-failure bound.
This provides a conditional direction for improvement, not an ordering of actual success rates.
