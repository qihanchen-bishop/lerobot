# 实验执行与作者确认清单

状态：计划，不是已完成结果。所有实机执行需要作者另行安排；本轮仅编辑论文。

## 运行前冻结

- 确认最终平台、任务、物体、相机位置、动作单位、控制频率、时限、完成阈值及持续确认窗口。
- 保存分割/基础/残差各阶段共同episode清单、采集源ID与派生文件映射；既有模型只能按已核实的独立性口径报告。
- 历史的3类物体、3×4网格和30/60/90数据预算均为待确认候选，不能据此填写最终设置。
- 冻结所有checkpoint哈希、数据与掩码版本、类别顺序、颜色表、动作归一化、查询定义、重规划/推理/残差配置。
- 指定独立训练种子数和每物体×位置×重复次数；运行顺序在匹配区组内随机化。不能按看到结果后追加某一方法试验。
- 将技术无效试验规则与算法失败区分：超时、失去有效计划、无效修正等保留为结果；外部故障另记原始日志及原因，按预先规则处理。

## 必做

1. RGB/语义关系 × 无反馈/历史反馈交叉比较，每行共用冻结基础checkpoint。
2. RGB、RGB+语义、加等量无监督查询、加关系监督查询四组，报告辅助资源。
3. 相同当前信息、计划特征、槽位和监督的MLP/GRU；匹配容量模型；当前对照若有历史估计速度须明确。
4. 匹配计算的输出屏蔽对照：保留反馈推理/接收/缓存，仅屏蔽发出残差。该功能待实现核验，不等于现有关闭残差开关。
5. 独立人工关系审核、可见性有效率、同槽位动作MAE/MSE、候选及采用后残差误差恒等式；无可靠专家标签的自主轨迹不做同索引伪比较。
6. 逐槽时间日志与失败视频，包含观测、提交、完成、计划ID、目标槽位、候选、实际采用/丢弃原因。缺失日志不得倒推补造。
7. 若保留样本效率主张，至少多示范预算、配对子集和独立训练种子；否则只称固定预算有效性。

## 可选扩展

- 当前/过往视觉与指令历史分解，历史置乱仅为依赖性诊断。
- 高频重规划和ACT时间集成，报告真实观测年龄、算力和执行模式差异。
- 训练后验与部署零潜变量关系精度、查询屏蔽和人工修正语义图，明确特权诊断。
- 温度与扰动诊断见 SEGMENTATION_EXTENSION_PLAN.md，不属于当前方法。
- 能复现状态和必要历史的仿真单步分支，随后同参考策略续行；否则不估计逐状态Q。
- 延迟和可见性扰动先离线/仿真；实机安全干预需要另行确认。

## 数据表字段

每次试验：trial_id、数据/模型/配置版本、训练种子、条件区组、任务、物体、位置、重复编号、开始结束时间、success、完成时间、失败类型、技术无效原因、视频路径、日志路径、标注人及仲裁。

每次反馈：观测时间、提交/开始/完成时间、计划生成时间与ID、目标槽位、基础指令、候选修正、最终指令、有效性及丢弃原因、历史长度和时间跨度。

主表按checkpoint和物体--位置条件报告成功/总数及区间。Wilson仅用于同一checkpoint同一条件的独立可交换重复。跨条件/跨种子聚合预先固定归一化权重并保留逐层计数，不对汇总总数直接套Wilson。配对差值保留匹配区组及独立训练层次；种子不足则描述性报告。成功时间以成功为条件，失败率和超时率同时给出。

可直接填数的空CSV及逐字段解释见 `../results_templates/README.md`。所有表复用trial_id、summary_id和来源清单，不代表新增实验，也不将同一试验在不同表中重复计入总体样本。
