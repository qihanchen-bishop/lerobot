# 理论命题—实现机制—实验结论核对表

审核用途：避免将数学成立、算法实现和实测有效混为一项结论。此表是作者工作文件，不应整表搬入论文正文。

| 论文对象 | 已核查的数学内容 | 实验能够支持什么 | 不能直接推断什么 |
|---|---|---|---|
| B2 示范动作误差界 | 在部署分布被总体示范分布覆盖、参考动作后果满足敏感性界时成立 | 独立动作误差、接触事件分层可作诊断 | 低经验训练误差不能证实覆盖；更低上界不能给出两个真实任务风险的排序 |
| C 信息损失分解 | 同一分布、参考延续和动作集合下，表示损失与决策实现误差非负且精确相加 | 关系读出和任务结果分别测试信息保留与学习后果 | 可读出性好不表示当前动作头实际使用了信息 |
| C 关系误差界 | 一致任务后果近似、有限关系敏感性与可测代理选择下成立；新增标量实例核算正确 | 独立人工关系标签、有效率和执行时刻探针支持可观测环节；可复现仿真中的干预可进一步检验局部任务后果 | 几何回归误差本身不是表示损失；同一伪标签的低误差不能证明真实关系正确；有限干预不能证明全动作域一致条件 |
| RGB 加语义 | 冻结分割器对同一 RGB 的确定性输出不增加物理观测；可以改变有限样本学习的归纳偏置 | 固定数据与资源披露下，RGB、RGB+语义、无监督查询、有监督查询的对照 | 不能称为替代 RGB；独立训练编码器之间没有自动的信息嵌套或无损保留保证 |
| 历史严格正价值 | 两模式例子中全部当前信息相同、历史揭示模式、评价仅取末步，价值严格为正 | 匹配当前信息与参数预算的模型对照，以及预先标注的动作—响应事件 | GRU/MLP 实测差不是理论最优历史价值；上一动作或速度已携带部分历史，不能忽略此混杂 |
| D 候选修正分解 | 潜在信息价值与基础决策余量减去表示、实现损失，得到相对固定参考的候选收益 | 相同基础检查点、输入与目标槽位的反馈对照 | 恒等式本身不证明现有动作监督压低了实现误差，也不是新学习算法的收敛结果 |
| D 采用与任务表现 | 在共同过程且参考动作确为 B 时，门控后的局部任务后果经性能差分精确连接整体成功率 | 与理论参考匹配的闭环任务比较；逐槽时序记录解释哪些候选得到采用 | 采用率、残差幅度或动作 MSE 不能换算任务收益；不同调度基线不能被无说明地代入同一 B |
| 固定机器人示范预算 | 本稿没有新的有限样本泛化定理 | 单规模支持该规模的效果；多规模、固定外部资源支持相应预算条件下的数据效率 | 不能从单规模推导样本复杂度；不能隐去语义标注与外部预训练资源 |

## 最小必需证据

1. **闭环主要结果。** 预先确认完成事件、时限、失败/无法评价/中止处理、条件单元、检查点、训练种子。保存逐次结果与视频关联。成功次数、分母与置信区间均来自同一可追溯记录。
2. **组合与组件。** 表示×反馈交叉设计，每行使用同一基础检查点；表示四组与当前信息/历史对照用于分离两条设计路径。没有显著交互时仍可报告各自贡献，不能自动声称协同。
3. **独立关系审核。** 探针拟合与评估按轨迹分离；区分计划时刻、反馈观测时刻与执行槽位时刻；不可见/未定义关系不填零误差。
4. **运行时对照。** 单工作线程调度下，保留“反馈计算照常但输出屏蔽”的参考组，与真正关闭反馈计算的系统基线分别报告。
5. **预算与适用范围。** 若主张数据效率，补多规模；若只有固定任务、固定关系与两个硬件实例，限定为该任务及硬件迁移范围。

## 可选的更强证据

- 可复现状态与必要历史的仿真单步分支，随后使用同一参考继续执行，以估计局部动作任务后果。
- 人工修正语义输入、历史重置/置乱或查询屏蔽用于故障诊断；这些干预可能改变分布，需与重新训练的公平对照共同解读。
- 调度扰动训练、分割校准和新的可见性审核管线属于新变体；没有实现和结果时留在研究计划，不作为当前机制。

## 可采用的结论范围

理论正文可以陈述“在所列条件下，关系保留与信息利用足以约束任务决策损失；有效修正通过共同过程上的性能差分连接任务表现”。

实验完成后，可根据真实结果陈述“在给定任务、数据与执行协议中，所提出的学习与执行机制改善了任务表现，组件对照和诊断支持相应机制解释”。若没有估计所有理论条件和常数，不应写成“实验验证了整个上界降低”或“证明了语义表示优于所有 RGB 表示”。
