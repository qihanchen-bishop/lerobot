\section{Experimental Evaluation}
\label{sec:experiments}
% 本节在双臂暴露与执行任务上验证方法，前序交互改变目标的可见性和可操作性。
This section evaluates the proposed method on a bimanual exposure and execution task.
The task requires coordinated actions under deformable occlusion,
where preceding interactions change the visibility and accessibility of the target.
% 先比较物体、位置和颜色条件下的表现，再验证标注、表示、反馈，最后扩展到手术模拟任务。
We first assess overall task performance across object categories, initial positions, and occluder colors,
then examine annotation reliability, semantic representations, and history-conditioned correction through controlled ablations.
Finally, we evaluate the framework on a surgical-phantom task to assess its applicability beyond the primary setting.

% 主要实验围绕四个问题展开。
The main experiments address four questions:
\begin{enumerate}
% 完整方法能否提高成功率，且收益是否在不同物体、位置和颜色上保持？
\item Does the complete method improve task success across objects, initial positions, and occluder colors?
% 质量感知迭代能否保持精度、减少异常并降低人工负担？
\item Can quality-aware iteration reduce segmentation anomalies and annotation effort while preserving accuracy?
% 语义和描述量监督分别有什么收益，感知质量如何影响这些收益？
\item What do semantic inputs and task-descriptor supervision contribute, and how does perception quality affect their benefits?
% 更新观测和历史能否减少错误并促进自然恢复？
\item Can recent observations and history reduce execution errors and support recovery from naturally occurring deviations?
\end{enumerate}
