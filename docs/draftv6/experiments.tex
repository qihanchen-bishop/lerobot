Wilson区间仅用于同一checkpoint、同一条件下可交换且独立的重复。
跨条件汇总预先固定条件权重，保留逐层计数；跨种子汇总另固定种子权重，
不将混合后的总成功数和总次数作为一个二项样本计算Wilson区间。
跨种子的比较保留配对结构，以训练种子和条件区组
为层次估计成功率差值区间；种子不足时仅作描述性报告，不用重复运行扩大有效训练样本量。
试验数、停止规则、技术无效判据和统计方案须在评测前固定。

完成时间仅在成功试验中计算，同时报告失败与超时比例，不据删去失败后的均值宣称整体更快。
算法超时、计划失效和有害修正均保留为失败；外部设备故障另记原因并按预定规则处理。
视觉结果由独立人工审核或冻结评价器结合人工复核得到，记录分歧与不可判断比例。

\subsection{Mechanism and Runtime Diagnostics}
\label{sec:analyticalexperiments}
离线动作比较使用同一回放分布、动作尺度、执行槽位与采样权重，
同时计算MAE/MSE、限幅饱和率和式\eqref{eq:residualgain}的对齐收益及修正能量。
自主轨迹缺少对应专家动作时，不使用原示范的同索引动作充当真值。
接触建立、拨空、滑脱和恢复事件预先定义并独立标注，
用于区分关系估计错误、当前信息歧义与无效调整。
这些统计解释机制，不直接估计理想历史价值或所有候选动作的后果函数。

逐槽保存观测、提交、完成和执行时间、计划ID、基础动作、候选、采用标记及丢弃原因；
报告端到端延迟分位数、更新间隔、历史窗口跨度和关键事件附近的采用率。
候选动作与实际采用后动作分别诊断，避免以总体采用率替代有效反馈收益。
调度为单共享工作线程、基础更新优先，目标更新频率不作为实际频率报告。
缺少候选或时间日志的旧试验标记不可追溯，不补造数值。
失败案例同时包括未纠正偏差与有害修正，并关联原始视频。

若需直接估计单步动作后果，仅在可复现状态及必要历史的环境中执行分支，
随后沿同一参考策略续行；否则以配对闭环结果为主要证据。
受控延迟和遮挡先在离线或仿真验证，实机干预另行确认安全条件。
自然失败分析不得称为受控扰动实验。
本章验证具体设计是否实现理论所刻画的机制，不以有限实验确认全局覆盖、稳定性或关系充分性。
