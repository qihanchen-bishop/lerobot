## 推导结构

A 定义双臂联合控制与完整任务完成目标。
B 从联合动作偏差连接到完整任务失败概率，再转向表示空间的覆盖与条件误差差异。
C 用可见性及交互几何描述任务信息，通过专家动作重构约束条件误差差异。
证明路线、符号和全部编号理论公式保持 v7 原样，仅修改必要的任务解释。
