# 从一般模仿学习分析转向双臂暴露与执行

## 本版定位

研究对象是一类任务：双臂通过改变可形变遮挡建立目标操作条件，完成规定操作，并在任务要求时恢复遮挡物。不是仅针对一块布、一个物体或一种机械臂推导，也不要求固定的阶段边界或两臂角色。

采用一般工具分析这类任务是合理的。任务的特点体现在系统、完成标准、动作后果和信息选择上，而不要求为每项任务重新发明数学定理。

## 叙述主线

1. **A：定义要完成什么。** 状态包括双臂、目标、遮挡物及交互条件；动作是联合指令。学习拟合专家动作，评价则关注暴露与后续执行组成的完整任务。恢复条件由任务实例决定，不等同于重新遮盖目标。
2. **B1：局部动作影响完整任务。** 暴露动作的价值包括其对后续操作的影响，而非只评价当前可见面积。原有性能差分恒等式连接局部动作后果和完整失败概率。
3. **B2：动作拟合何时有用。** 覆盖要求包括交互后可能出现的历史；敏感性约束联合动作偏差引起的任务后果。接触切换与遮挡变化并不自动满足这些条件。
4. **B3：为什么分析表示。** 合并与动作无关的外观差异可能放宽覆盖要求，但不能混淆需要继续暴露与已可执行操作的情形。上界仍受覆盖与条件误差差异共同影响。
5. **C：表示需要保留什么。** 以可见性和目标、工具、遮挡物、目标区域的空间关系为任务信息候选，配合本体及可用执行上下文。通过描述量估计、专家动作重构和条件误差差异，回到原有任务失败上界。

质量感知标注控制监督来源的可靠性；语义输入突出对象结构；任务查询鼓励编码器保留可见性及几何关系。它们针对理论给出的设计方向，不直接验证覆盖常数或保证部署重构误差。

## 审阅重点

重点检查第三章 A 的任务范围是否准确、B 的动作后果是否体现前后操作耦合、C 的描述量是否与实际实现相符。具体成功阈值仍留在实验，不放入一般推导。
