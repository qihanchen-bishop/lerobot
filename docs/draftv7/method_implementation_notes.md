# Method 定稿核对

更新：2026-10-26。本文件是内部实现核对记录，不编入论文。

## 已核对并同步的内容

依据 mycode/view_qtoken.py 中 FilteredHardSegmenter、view_geometry、quality_weights 与 query_loss，以及 mycode/prepare_view_qtoken.py：

- 当前 viewQtoken 使用硬语义彩色图。训练读取离线分割；部署由冻结 U-Net 生成类别，再进行结构过滤。不是训练过程中端到端更新分割器。
- 三个共享查询对应双视角的面积、工具--目标向量、目标--区域距离，合计八维。每个视角有独立读出，不融合不同相机的像素坐标作为一个几何标签。
- front 工具参考点为归一化坐标中的 PCA 线段左端点；side 为工具质心。
- 区域距离是可见目标像素到固定区域多边形的最大距离，按图像对角线归一化。固定区域从训练标签离线估计，不使用实机测试目标位置拟合。
- 质量权重取相关类别分数的最小值，并与异常排除、几何有效性组合。
- Smooth L1 的 beta=0.01，每个视角读出头按几何有效坐标数归一化，再平均六个头；不除以质量权重之和。
- method.tex 和 method_details.tex 已同步以上定义。理论章节及其编号公式保持不变。
