# 理论条件与验证顺序

本文件是待验证计划，不是已完成实验的报告。避免再增加大量同时变化的模型。

最新优先顺序与用户提供的近似成功率见 `evidence_to_experiments_zh.md`。
具体任务判据只在实验章节实例化：布料占整幅参考画面的比例，不是对目标物体的覆盖率。
主文理论保持通用，以下是实验检查项而非通用任务约束。

## P0：先整理已有效果

相同策略示范数据、相同训练轮次已由用户确认；以下记录工作不是质疑这两项，也不要求因此重跑。

固定每个方法对应checkpoint、训练seed、训练episode、所有预训练数据范围、action目标、归一化、
部署控制频率、replan、TE系数、端到端延迟、成功判据和timeout。
按相同初始条件配对，区分独立试验次数与视频帧数。
已有“提升10+%”需明确相对百分比还是百分点，以及分母和对照，不在正文猜测。

## P1：检验误差与成功的联系

- 相同未见episode上重算执行槽位MAE和MSE，另外保留全chunk误差。
- 按暴露、分离、首次接触、接近区域边界和普通运动分层，不使用固定时间均分。
- 独立计算实机成功率及失败阶段。不能用自主轨迹的同一时间索引专家动作当作天然反事实真值。
- 关键状态动作误差下降而全局变化较小，且该阶段失败减少，才支持任务相关性解释。
- 分层只是诊断，不等于已估计Q函数或证明所有状态的价值Lipschitz常数。
- 部署状态到示范的特征距离仅是覆盖代理，不宣称估出了严格密度比C。

## P2：语义输入的有限数据价值

最小主对照：RGB ACT vs RGB+语义，固定已有有效结构。
补充同token预算重复RGB对照；对训练数据量做少量档位，而不是再搜很多结构。
保持几何不变改变背景/纹理，检查语义是否仍可靠及动作是否稳定。
独立人工审查关键状态mask，按类别报告错误，不只看全局IoU。
语义噪声扰动应在合理范围内，区分标签质量变化与额外标注量增加。
结果若只在见过的颜色有效，不应写为通用外观不变性。

## P3：QToken是否在帮助决策

同一语义基线：无query、相同query但无几何监督、有几何监督。
几何MAE按有效域报告；不可见时目标面积零必须纳入。
执行query屏蔽/替换与动作变化诊断，再做必要的配对实机对照。
屏蔽是分布外干预，需与训练时无监督query对照结合，不能单独作为因果证明。
目标区域质心距离不足以判断完整进入区域，完成率使用独立标注判据。
先不添加阶段头，以免改变当前问题。

## P4：GRU残差为什么优于当前反馈方式

同一个基础checkpoint固定，最少比较：
1. 固定replan执行。
2. 高频ACT最新预测，不做TE。
3. 高频ACT加TE，记录实际系数。
4. 当前帧MLP残差。
5. 相同输入预算的历史GRU残差。

同时报告真实可达到频率的部署结果，以及匹配观察年龄/延迟的机制对照。
不能把不同基础策略的A/B/C直接当作记忆架构单变量对照。

先用离线同目标槽位数据计算：
- base MSE、corrected MSE。
- 2 E<error,residual>，E||residual||²，检查净增益恒等式。
- history置乱/移除、最新观察延迟、计划输入移除的影响。
- 高龄旧预测与最新预测在事件后的偏差、实际TE权重。
- 以上离线诊断不是自主偏离后的正确恢复标签。

实机记录：
- observation timestamp、plan ID、target timestamp、接收与发送时间。
- P50/P95/P99端到端延迟、迟到前缀数量、有效修正覆盖率。
- 首次接触失败、拨空气、拨远、再遮挡、未完成复原等事件。
- 受控小扰动下的局部恢复，与大偏离无覆盖状态分开。

## P5：论文可以说到哪一步

已有实机改进：可以报告在明确平台、任务及协议下有效。
固定分布MSE改进：可以支持残差预测精度，但不能替代成功率。
历史消融有效：支持历史被利用，尚非全局状态可观测性证明。
几何探针有效：支持可读出，尚非动作使用或阶段理解证明。
覆盖/光滑性仅局部证据：报告条件性解释，不写全局收敛保证。
未知关键状态：需要额外示范、交互、动力学或传感信息，不由语义自动解决。
