# 理论叙述的递进关系

## 一句话主线

理想条件下，动作误差可以支持任务成功率下界；现实中的有限数据、有限覆盖及信息缺失使该保证难以直接成立。语义与任务关系监督尝试改善已有观察的任务相关表示，新观测与历史残差进一步处理表示本身无法消除的动态与时序缺口。

## 1. 从理想保证开始，而不是从模块开始

需要可靠参考策略、参考动作与执行时刻一致、泛化误差受控、部署状态覆盖受控以及适当的任务敏感性。

这里的答案是成功率下界，不是平均loss对真实成功率的必然排序。

## 2. 现实中有三个不同缺口

- 有限数据：控制关系可能已经出现，但从高维外观中识别和保留它仍然困难。
- 有限覆盖：无关外观组合没有穷举，与完全没见过某种控制状态，是不同的问题。
- 有限信息：当前帧可能不能区分动态状态，旧观察也没有记录执行期间的新变化。

它们不能被一句“加语义就解决分布偏移”混为一谈。

## 3. 为什么先讨论关键状态

关键状态并不是按人工直觉给一个名称，而是指动作偏差对后续任务风险更敏感的状态。

稿件新增了状态敏感性 w(t,x) 的界，使需要控制的动作风险变为：
epsilon_E,w = E_expert[w ||action_error||²]。

它回答“哪些状态上的误差更值得改善”，但没有回答“用什么表示改善”。

w 是分析变量，不是当前实现里新增的训练权重，不是分割质量分数，也不是已测出的任务价值。

## 4. 关键状态与语义、QToken的真正联系

中间必须有一个条件：

这些敏感状态中，需要区分的控制关系能够被所选语义几何可靠表达。

成立时：
语义标签提供对象先验 → query监督要求关系在编码中可读出 → 动作头利用关系 → 相应状态上的预测误差可能降低。

不成立时：
关键差异来自不可见作用力、完全未知动力学，或监督了与当前控制无关的几何，就不能靠上述路径补足。

因此，视觉上明显、分割IoU高、辅助头准，都不能单独替代这一条件。

## 5. 怎样把两章公式真正连接

新增归一化的任务敏感性加权分布 mu_w。
几何表示界在同一 mu_w 下重新定义全部条件均值和误差，得到动作风险界；
再通过前一节的加权任务界，得到条件性的成功率下界。

这样不是两个无关公式并排放：
几何充分性误差、几何估计误差、动作读出误差，出现在同一条任务性能界中。

仍需保留的边界：
- 加权风险必须对应同一参考动作与执行时刻。
- 覆盖必须成立；未覆盖部分不能凭空删除。
- 不宣称语义自动改变物理敏感性或降低覆盖系数。
- 更小的上界仍不直接证明两个真实策略的成功率排序。
- 任务权重若不可获得，关键事件分层只是实验代理，不能声称已经数值认证整条界。

## 6. 为什么表示之后还要引入残差

即使现有观察的语义和关系完全正确：
- 原计划生成后发生的新变化仍然未知。
- 相同当前画面仍可能对应不同速度或接触状态。

这些不是继续减小同一帧分割误差就能消除的问题。

最新观察扩大因果信息；历史有机会区分动态歧义；残差明确学习这些信息对当前计划的修正。
实际收益必须是可预测误差减少超过编码、拟合和时序代价。
这解释了为什么方法需要后续模块，而不声称GRU是唯一解。

## 7. 现有实验如何对应

相同策略数据、相同训练轮次已确认，这是共同实验基础。

- 语义与QToken收益：检查是否改善需要区分的任务关系，以及相应关键事件失败是否减少。
- MLP与GRU收益：检查历史是否增加可预测残差，排除容量、视角和端到端延迟变化。
- 完整系统收益：检查表示与反馈分别解决了哪些剩余错误，而不是只将成功率逐行相减。

不必增加一批新模块。先使用已存日志、同基础策略消融和少量匹配对照，把每个箭头对应的证据补上。
