# 从实机证据到理论解释，再到补充实验

## 文章主线

不是“先假定模块有效，再找公式证明”，而是：

实机观察 → 多种可能解释 → 明确适用条件的理论 → 能区分这些解释的对照实验。

已有成功率支持这些模块值得研究，尚不能唯一确定收益机制。实验与理论应相互修正。
理论部分描述任务族和信息/表示/反馈的作用；对象、颜色、网格、具体判据及百分比放实验部分。

## 通用问题表达

- 环境具有部分可观测、动态、非线性和可能的模式切换。
- 多个执行器可以通过共同环境耦合，但方法定义不固定机械臂数量。
- 任务由完成函数 Phi_l(z[0:T]) 定义，z是任务相关评价变量。
- 不要求所有任务使用同一阶段数、语义类别或阈值。
- 若只需某时刻同时满足若干条件，Phi是“时限内存在一个满足所有条件的时刻”。
- 若另一个任务要求顺序或持续保持，再在该任务中定义对应时序条件。
- 视觉可评估是声明的适用条件，而非所有物理任务的定理。
- 单帧可评价成功不意味着单帧足以决定动作。历史的价值来自运动、接触及执行偏差的歧义。
- 理论不假定必须有阶段头、GRU、快慢模型或在线完成评估器。

## 当前任务的准确实例

目标：在时限内，物体完整位于目标区域中，同时布料占参考画面的面积比例达到设定阈值。

布料不会重新覆盖目标物体。分母是整幅参考画面的面积，不是物体面积，也不是默认换成桌面ROI。
不需要用最终目标被遮挡来论证历史的必要性。

完成帧应同时满足两项，不应只记录“曾经入区”后就忽略物体是否移出。
如果物体和区域完整可见，两项可在同一帧评价。连续确认帧数和数值阈值仍待协议确定，不从旧实验推定。

互斥分割的可见region与object不会相交，因此需用完整目标区域足迹判断包含，而不是直接求两类mask交集。
评价最好独立于策略的分割器并有人工审核，避免评价循环。

## 初步结果

以下均为用户口述的近似值，不是本轮重新统计：

用户已确认：各组策略示范数据相同、训练轮次相同。这两项已控制，不再作为未知因素或重跑理由。

| 方法 | 成功率约 |
|---|---:|
| ACT | 50% |
| ACT + MLP残差 | 60% |
| ACT + GRU残差 | 70% |
| 语义输入，无QToken | 70% |
| 双视角语义 + QToken | 80% |
| 语义 + QToken + QTokenGRU | 87% |

没有为这些比例推算整数成功次数、置信区间或p值。
必须逐项核对视角、基础checkpoint、测试分母、重复轮次和初始条件。
尤其不能在单视角语义与双视角语义QToken之间，把全部提升归因于QToken。

## 三个待解释机制

### 语义及几何表示

解释：外部监督提供对象先验，QToken促使任务关系在表示中可读出。

理论对应：同RGB的语义不增加理想观测信息，但可以降低表示损失及有限数据读出误差。
不能保证分割越准成功率就越高；误差需发生在对当前任务有用的关系上。

优先补充：固定双视角、token预算、数据与训练协议，对照无query、无几何监督query和有监督query；
检查几何精度、动作对query的依赖、拨空与有效接触事件。
如果当前缺少“双视角语义但不加QToken”的匹配结果，这个比再加新模块更优先。

### 当前反馈及历史

解释：MLP修正当前计划误差；GRU进一步区分相同当前画面下的运动/接触差异。

理论对应：历史中可预测的残差应超过编码与拟合误差。
当前任务终点可见不削弱这一动机，因为完成判别不是动态控制状态估计。

优先补充：同一个ACT基线下无残差、MLP、GRU；窗口置乱、只留最新记录和相近容量/相同历史的非循环对照。
如果MLP本来只看当前帧，不能把GRU-MLP差异单独归为“GRU网络比MLP强”，它同时改变了信息。
同样应排除不同实际延迟导致的差异。

### 表示与反馈是否互补

解释：表示减少错误的任务关系判断，残差减少执行过程中累积的局部偏离。

优先补充一个匹配2×2，而不是把六行近似结果当严格递进消融：

| 基础表示 | 无残差 | 同配置GRU残差 |
|---|---|---|
| RGB | 待填匹配结果 | 待填匹配结果 |
| 语义+QToken | 待填匹配结果 | 待填匹配结果 |

需要固定视角、平台、训练/评测划分及反馈预算；不同基础模型的query输入差异应披露。
如果要单独归因于query作为残差上下文，还需在同一QToken基础模型下关闭/使用query上下文。
87%支持完整系统有价值，但“协同”是额外假设，不由它高于80%自动成立。

## 位置泛化：现有设计最值得立即拆分的结果

训练6格：
(0,0)、(0,3)、(1,1)、(1,2)、(2,0)、(2,3)。

测试12格：
行0–2、列0–3。

未采集的6个初始化位置：
(0,1)、(0,2)、(1,0)、(1,3)、(2,1)、(2,2)。

三个物体形成每轮36个条件单元，其中18个来自已采集初始格，18个来自未采集初始格。
分别报告两个子集和每个物体的成功率，而不是只报整体。
这是工作区内初始化位置泛化；不是新物体类别、新颜色或工作区外推。
示范轨迹可能经过测试格，因此不能直接称为严格未见状态泛化。

## 最少先做什么

1. 不新增网络，先补齐六行结果的实际计数、视角、seed、协议，拆分新旧位置和失败事件。
2. 固定基础策略做MLP/GRU的历史及时间对齐对照。
3. 固定双视角语义基线做QToken的监督与容量对照。
4. 复用已有匹配结果组成2×2，缺哪个补哪个。
5. 主结论明确后再做有限的数据量、扰动或跨平台扩展，不同时展开一大批新结构。

已有结果是论文的起点；理论最有价值的产物，是以上可被实验反驳的机制和优先级，而不是更多与系统脱节的公式。
