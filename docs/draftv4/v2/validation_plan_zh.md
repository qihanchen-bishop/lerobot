# 理论到实验的最小证据清单

这是正文单段实验概述的执行说明，不表示本次已运行这些实验。先归档能复用的实机记录和checkpoint，再补缺失对照；不要求一次把所有组合全跑。

当前修订已按用户确认将三个模块实机有效作为经验事实。这里列的是对已有结果的归档与机制分析口径，不是把已完成的实机工作重新写为未开展。
新增理论中的基线表示损失下界不能由有限能力probe的较高误差直接推出；如无法认证该下界，报告条件性分析与实机效果，不声称具体checkpoint已满足严格比较定理的所有前提。

## 1. 先固定主张和主对照

主要结果是任务级成功与失败恢复，动作误差是诊断，几何误差是中间机制。每个结果绑定数据版本、分割器、基础checkpoint、残差checkpoint和执行参数。
主对照为同视角RGB ACT、语义ACT、QToken ACT、对应基础策略+GRU残差；DP可作为另一类策略基线，但只有ACT残差实现时不声称对DP也已验证。
单/双视角分别比较。A/B/C全系统差异不等同于同基础策略下的残差输入消融。

## 2. 实验与可反驳论点

| 实验 | 固定条件及改变因素 | 首要指标 | 不支持主张时怎么解释 |
| --- | --- | --- | --- |
| 标签迭代 | 相同视频与类别，迭代前后；质量诊断移除对照 | 独立审核IoU/边界/几何误差、人工分钟、漏标率 | 高分但错标，说明诊断不能检测该误差，不能称不确定性已校准 |
| 语义输入 | 相同RGB数据/视角/种子/预算；语义对比重复RGB | 任务成功、事件到达率、动作误差 | 仅额外token有收益时，语义特异性证据不足 |
| 几何query | 相同query结构，辅助监督有/无；同checkpoint干预 | 真实几何读出、事件附近动作、成功及失败类型 | 读出改善而动作不变，只能声称表示可读出 |
| 新观测 | 固定慢checkpoint与调度；仅计划上下文对比最新视觉 | 同目标槽MSE/MAE、实际残差风险差、扰动恢复 | 最新视觉未改善，不支持新观测是收益来源 |
| 额外历史 | 最新记录MLP、同GRU仅最新记录或重复最新记录、真实历史 | 同目标误差、恢复、延迟与参数量 | 完整GRU胜过基础但不胜过当前记录，不支持历史增益 |
| 慢query对快分支 | 同QToken基础checkpoint，C残差有/无慢query，分别训练 | 同目标误差与实机恢复 | A/C直接比较不能替代该实验 |
| 调度 | 相同模型/设备/负载，注入时延与丢帧，跨计划切换 | p50/p95/p99端到端时延、有效覆盖、过期丢弃、成功 | 超时但模型平均耗时低，说明工程链路仍不满足预算 |

训练消融与推理干预互补：只把query置零或置乱可能制造分布外输入，不能单独作为因果证明。历史对照保留相同速度、上一命令与计划信息，避免偷偷移除其他输入。

## 3. 进展与恢复如何定义

在盲于策略名称的独立视频审核中标出目标初现、分离、入区和恢复结束事件。目标全体入区不能只用质心距离判定；遮挡状态下不能把不可见等于已入区。阈值与稳定持续帧数在验证集确定后冻结。
若沿用95%像素包含等历史标准，应记录可见表面假设与分母定义，并检查它是否适用于两平台。不要在看到各方法结果后调整阈值。

拨空气以明确的工具运动、目标接触证据和目标响应条件定义，视频标注允许不确定项；仅二维距离小不能证明真实接触。
恢复率分母为所有预先规定且确实施加的扰动试验，不能只挑看上去能恢复的片段。
完成后无效动作、进入恢复阶段的延迟可衡量进展相关行为，但没有停止头就不报告不存在的停止头准确率。

## 4. 风险恒等式怎么测

固定测试episode、慢计划、目标槽位及有效性掩码，收集归一化示范指令Y、基础B和实际应用残差r。按相同权重计算：

```text
measured_gain = mean(||Y-B||^2 - ||Y-B-r||^2)
alignment = 2 * mean(dot(Y-B, r))
magnitude = mean(||r||^2)
assert measured_gain ~= alignment - magnitude
```

超时回退的槽位取r=0，不能只报告成功返回的槽位；同时报告条件于接受的效果和全部目标的效果。按关节、计划年龄、事件/遮挡状态分层。这个检验只验证代数与实测收益，不识别Bayes条件均值或独立证明历史收益。

## 5. 公平与统计

使用配对初始位置与物体、随机化策略运行顺序，建议至少三个训练种子并分别记录重复实机试验。种子/任务/episode不能混成独立视频帧来扩大样本数。报告每任务、每平台和预先定义的汇总，置信区间按实际独立层级构建。
任务耗时不能只报成功轨迹均值而忽略失败；同时给出固定时限成功率和超时计入方式，必要时使用删失时间分析。训练种子数量与试验量应按预期效应和可用预算确定，不保证任意小样本具有统计功效。

高频完整ACT、temporal ensemble等对照明确其观察频率、真实可用延迟、执行长度和算力；报告相同更新频率与相同算力预算两种比较口径，不能把离线零延迟ACT和实机排队残差直接比较。

## 6. 既有结果与新实验优先级

优先整理已验证的语义/GRU实机记录进入主结果表；随后补同基础checkpoint的最新帧与历史对照、query利用证据、端到端时延。再补标注成本和独立质量审计。最后依据主要论点的缺口选择未见物体或受控仿真，不为了堆平台而扩大实验范围。
旧日志若没有记录某项关键量，不得事后声称已经测得；可对固定checkpoint重新离线评测，但离线重放不能替代扰动后的真实闭环行为。
