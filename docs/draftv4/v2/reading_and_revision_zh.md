# 三篇T-RO的论证方式与第二版修改依据

日期：2026-09-09。阅读对象为literature目录中的三个期刊作者稿，重点逐节核对引言、建模、方法、实验和局限；不照搬原文，也不将其结论转写成本文已证明的结论。

## 1. 从论文中学习什么

### Bobu等，T-RO 2020

[全文](https://arxiv.org/html/2002.00941)。重点：III问题定义；IV/V算法及近似；VI案例；VII用户实验；VIII局限。

它从假设空间无法解释输入这一失效出发，建立联合置信度推断，再分别落实到示范与在线纠正。案例不是只展示成功，还检查特征相关导致的误判。值得借鉴的是把建模、可计算近似和经验支持分开，并用明确实验问题检验边界；不是把它的置信度当成我们的SAM2质量分数。

### Zeng等，TossingBot，T-RO 2020

[期刊作者稿](https://arxiv.org/pdf/1903.11239v3)。重点：III任务与基本模块；IV残差物理；V监督来源；VI-B/C/E/F/G对照、机制与泛化；VII局限。

它从简化弹道控制遗漏真实因素出发，明确基础控制与学习残差的分工，并用纯解析、直接回归和混合方案检验选择。抓取监督来源及未见目标位置的实验解释模块为何有用。我们的基础项是ACT而非物理公式，不能继承其解析泛化能力；应学习这种可区分职责的论证。

### Ablett等，T-RO 2025

[期刊作者稿](https://arxiv.org/pdf/2311.01248v5)。重点：III-C/D示范与力匹配；III-F校准落实；III-G/H模式监督与训练；IV-D/E/F/G/H模块、切换时机、输入与数据量；V局限。

它从示范回放不能复现接触力的问题出发，在静态弹簧关系下推导目标位姿，再落实到触觉测量与校准。实验分开考察数据构建、输入和模式切换，也检查切换相对实际接触的时间。对我们的启发是让中间量验证与任务结果相互补充，不把多个模块合并后的提升全部归因给某一个模块。

## 2. 第一版的问题与第二版选择

第一版是理论材料库：结论大多带有必要限定，但小节多，公式之间缺少一个贯穿全文的问题；方法像实现说明，读者容易记住SAM2、U-Net、QToken、GRU四个模块，却不清楚它们共同解决什么。第二版保留其正确边界，重建叙述顺序。

中心问题：在遮挡接触任务中，如何以较少额外人工标注，让动作块策略获得可读出的任务进展线索，并利用新观测与历史及时纠偏？

| 问题 | 分析导出的路径 | 方法落实 | 必须独立检验的证据 |
| --- | --- | --- | --- |
| 关系未被可靠表示 | 几何相关性、读出精度、动作利用缺一不可 | 语义输入+三个几何监督query，保留RGB | 几何准确率、动作干预与行为，而非只有辅助loss |
| 自动监督可能错 | 拟合伪标签误差不等于真实几何误差 | 质量诊断、局部重试、少量复核、几何软加权 | 独立审计错误与人工成本，困难转场保留率 |
| 执行时计划观测已旧 | 新观测可能解释原计划的条件误差 | 冻结计划+新RGB+有界残差 | 同基础checkpoint、同目标槽位的纠偏收益 |
| 单帧不能区分趋势 | 历史增量收益必须超过编码与拟合代价 | 特征缓存+窗口GRU | 同输入最新帧对照、历史干预、同结构无额外历史对照 |
| 算对了但返回太晚 | 正确目标时间与有效覆盖是适用前提 | delay/stride/horizon、plan ID、过期丢弃 | 实际目标覆盖、延迟分布、跨计划不污染 |

## 3. 第二版的核心理论及本次修订

初次第二版采用了新观测、历史与残差的统一分解。用户指出不应在问题定义中预设快慢结构，故当前进一步改为共同任务目标下的三条比较路径（以下替代初次第二版的组织方式）：

```text
任意表示的动作风险 = 共同Bayes风险 + 表示信息损失 + 实际读出误差
新增原RGB的风险收益 = 条件均值信息收益 + 旧实现误差 - 新实现误差
几何表示的改进保证：本方法风险上界 < 基线表示损失下界
GRU残差的风险收益 = 历史可预测误差能量 - 编码损失 - 残差逼近误差
相对理想当前输入残差的额外收益 = 历史增量信息收益 - 编码损失 - 残差逼近误差
```

现在问题定义只包含隐状态、观测、任务成功目标和示范代理风险。残差参数化在第三条路径才引入；时延是方法适用条件，不是单独任务。实际能直接测的是两种策略的同分布误差、残差与原误差的内积、残差能量；不能把不可见条件均值或Bayes风险当成已经测得的实验指标。标准投影关系不包装成新的基础数学发现。

语义部分不声称同帧信息增加，但增加了真正的条件性比较结论：几何关系近似充分、可读出且动作读出误差足够小时，方法风险上界可以低于存在关系混叠的基线下界，从而严格优于该基线。下界不是凭实机成功率假设出来的；附录给出双模式表示混叠的构造。若RGB表示本身已充分，不能套用这个正下界，改善可能来自更容易拟合的读出。

query的特定作用由几何头对各token的监督梯度、其图像聚合路径及动作decoder的可访问性解释。辅助准确但动作头不使用相关关系是明确反例。没有证明三通道调色板、共享ResNet、三个token或GRU在所有选择中最优。

附录补充了理想梯度更新下的局部比较保证：几何辅助更新与动作下降方向一致且曲率代价足够小时，联合更新的动作loss低于仅动作更新。这个结论不假装是当前AdamW的完整收敛证明，也不把一步训练loss下降当成泛化或实机保证。

可见性也属于条件：未定义的距离没有监督，不能用可见子集的几何误差证明不可见时的风险。基线信息损失下界是理论假设或严格构造，不可用一次线性probe误差充当其证明；probe误差还包含读出不足。

## 4. 对已经验证的实机结果如何写

用户已反馈语义和最新GRU残差有实机改善，这些是研究动机及结果组织的现有基础，不应写成完全尚未尝试。此次没有重新读取最新原始实机日志，因此正文不编造提升百分比、显著性或跨平台汇总。实验章节按用户要求是一段验证概述，后续把真实记录放入对应位置。

最新补充（2026-09-09）：用户报告GRU在实机上表现更好，提升约10+%。目前未明确这是成功率的百分点差、相对百分比，还是其他指标，比较对象及试验分母也未随消息给出。摘要和引言纳入了定性的实机改善事实；不把10+%擅自改写为10多个百分点，不声称已达到统计显著性。补充指标口径、基线、平台/任务、两组成功数与总数后，再正式填写数值结果。

随后用户明确上述三点均已实机测试有效。本次将其作为当前任务中的经验事实保留，修订目的在于解释和界定理论保证，不是要求重新证明模块从未做过。原RGB、最新原RGB和分割生成的语义RGB具有不同信息关系，正文分别处理，避免术语歧义造成错误信息论论断。

需要区分三层主张：方法整体有用；某个模块确实被利用；推导中的具体机制解释了收益。前一层成立，不自动保证后一层。新实验主要补充机制证据和公平对照，不是要求无差别重跑所有既有结果。

## 5. 不扩张研究范围

- 不新增阶段状态机、CLF-QP、强化学习、跨视角三维补全或action-supervised segmentation。
- 当前QToken不直接输出终止信号。任务完成可表现为合适的动作变化，但要声称完成检测能力，须有独立输出及对应评测；本文不假装已有。
- A/B/C保留为方法变体，但换基础策略与换快输入同时发生，不能当作严格单变量消融。
- Related Work暂留空。三篇是组织写作的参考，不足以证明本文新颖性或投稿档次；完整动作块纠偏、对象中心表示和低成本标注综述仍需补齐。
- 没有复制他人贡献清单或假设；公式的适用条件由本任务的信息流决定。
