## 结构

1. 引言：一个任务目标，观测、任务相关表示与历史纠偏三种途径。
2. 相关工作：暂留空，保留正文依赖引用。
3. 问题定义与性能条件：架构无关定义；RGB、几何监督表示、GRU残差的严格条件性比较。
4. 方法：逐段说明模块针对哪个分析项，区分已有实现与评测约束。
5. 实验：按要求用一个段落概括对应验证，不虚构数据。
6. 讨论及附录：不适用情形、标准证明、基线表示混叠下界、质量偏差和时间覆盖。

`reading_and_revision_zh.md`说明三篇论文的学习结果、修改理由和证据边界。
`literature/README.md`记录下载来源、版本、SHA-256，三篇PDF仅保留本地，不自动进Git。
`validation_plan_zh.md`把实验概述展开为后续填充结果时的检查表，不扩写正文实验段落。

本次仅修改文稿，没有改训练或推理代码、没有启动实机和训练、没有同步GitHub。
方法沿用draftv3与第一版的已核对实现，并再次检查当前几何loss的组内坐标归一化。
用户已验证的实机提升不被否定；本次未重新汇总原始实机记录，故不填数值。
