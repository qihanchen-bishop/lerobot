## 1. 全章论证主线

> A 定义研究对象；B 说明动作模仿误差与任务成功之间缺少哪些条件；C 分析怎样改善有限数据下的任务关系表示；D 分析怎样利用执行中的新证据和历史纠正当前计划。

| 小节 | 核心问题 | 应交付的结论 |
|---|---|---|
| A | 研究什么任务、什么信息与学习设置？ | 有限固定示范、离线训练、视觉动作决策与视觉可评估性 |
| B | 为什么训练拟合好仍可能任务失败？ | 泛化、访问覆盖、任务敏感性和信息时效共同限制训练误差的解释 |
| C | 在已有观测中，怎样让关键决策依据更容易被学到？ | 可靠任务关系监督可能改善表示保留和实际读出，但收益取决于相关性、质量与使用 |

## 2. C 的核心观点与结构

建议标题：

**C. 有限示范下的任务相关表示**  
**Task-Relevant Representations under Limited Demonstrations**

核心观点：

> 语义先验的价值不在于给相同 RGB 增加新信息，而在于让有限示范更有效地约束决策所依赖的对象关系；只有这些关系与动作有关、估计可靠并被动作预测实际使用，才可能减小任务相关误差。

建议采用“总述 + 四个分述”，而不是保留现稿七个较细的小标题。

### C.1 从视觉输入到任务关系

段落职责：明确“语义”“关系”“进程”三个层次，建立选择表示的理由。

叙述顺序：

1. 承接 B：有限动作监督可能无法区分依赖背景的映射与依赖真实任务关系的映射。
2. 语义区域提供对象角色和空间范围；任务关系表达对象之间对操作有用的联系。
3. 相对位置、可见程度及其变化可以承载任务进程线索，但不能把“进程”等同于时钟或某一个面积阈值。
4. 分割由当前 RGB 确定时，作用属于学习先验；标签、预训练和人工审核应作为额外监督资源披露。

用 VIOLA 和 Transporter 支撑结构先验的动机；DBC/TIA 用于说明“任务相关”应与行为后果关联，不照搬奖励/转移建模。XIRL 仅用来支持进程表示的思路。[VIOLA](https://proceedings.mlr.press/v205/zhu23a.html)、[Transporter](https://proceedings.mlr.press/v155/zeng21a.html)、[XIRL](https://proceedings.mlr.press/v164/zakka22a.html)。

一般理论中不限定布料、双臂或特定阶段；这些在方法和实验中实例化。

### C.2 表示改善作用于哪部分误差

段落职责：给出语义可能有效的数学位置，不重复 B 的旧观测/新观测分解。

沿用 B 的共同评价分布、同一目标执行时刻和归一化动作目标 \(Y\)。训练后参数固定，比较变量二阶可积。完整允许信息记为 \(\mathcal F\)，学习表示 \(Z\) 由该信息产生，动作预测 \(p_Z\) 仅使用该表示。

先描述对象，再给一个主要关系：

\[
R(p_Z)=R(m_{\mathcal F})
+\underbrace{\mathbb E\|m_{\mathcal F}-m_Z\|^2}_{a_Z}
+\underbrace{\mathbb E\|m_Z-p_Z\|^2}_{e_Z}.
\]

其中 \(R(p)=\mathbb E\|Y-p\|^2\)，\(m_{\mathcal F}=\mathbb E[Y\mid\mathcal F]\)，\(m_Z=\mathbb E[Y\mid Z]\)；\(a_Z\) 为表示损失，\(e_Z\) 为实际动作读出误差。

这一关系需要 \(\sigma(Z)\subseteq\mathcal F\) 与相应可测性。语义辅助可改变后两项；它不能降低相同原始信息下的理想预测风险。后两项也可能因错误监督、容量限制或优化困难上升。

正文说明这是条件期望投影的应用，证明放附录。有限示范解释为什么实际读出误差重要；这里不声称已经推导出新的样本复杂度率。

### C.3 关系监督何时足以支持动作改善

段落职责：从抽象表示损失落到可监督、可检测的任务关系。

任务关系 \(G\) 和必要控制上下文 \(\chi\) 共同决定参考动作的近似预测依据。拟设一个明确的 Assumption：

- 存在关于 \(G\) 为 \(L_G\)-Lipschitz 的函数 \(f(G,\chi)\)，使 \(\mathbb E\|m_{\mathcal F}-f(G,\chi)\|^2\le\epsilon_{\rm suf}\)。
- 关系估计 \(\widehat G\) 可由表示读出，控制上下文 \(\chi\) 同时包含在实际读出可用的表示中。
- 关系估计风险为 \(\epsilon_G=\mathbb E\|\widehat G-G\|^2\)。

这样可保留现稿的条件性命题：

\[
R(p_Z)-R(m_{\mathcal F})
\le\left(\sqrt{\epsilon_{\rm suf}}+L_G\sqrt{\epsilon_G}\right)^2+e_Z.
\]

这不是假定几何完全决定动作；\(\epsilon_{\rm suf}\) 表示所选关系与上下文尚未解释的部分。必要上下文不能在证明中使用、在实际表示中却不存在。

**关系更准确、关系可读出、动作确实使用关系，是三个不同层次。** QToken 辅助监督直接约束可读出性，对动作的作用还须通过对照验证。保持 RGB 路径允许利用未被类别标签表达的线索。

任务进程在这里应表述为“关系及上下文所携带的进程线索”；当前 Method 没有显式阶段头，不能写成已实现阶段识别、阶段切换或任务停止。

### C.4 可靠性、任务后果与剩余缺口

段落职责：集中说明结果的适用边界，并自然引入 D。

可靠性用少量明确结论概括：

- 伪标签拟合好不代表真实关系准确；系统性误分可同时具有高置信度和高时间一致性。
- 目标不可见时，“可见面积为零”可能有定义，但目标与工具距离可能没有定义；用有效性标记区分，不能把缺失距离标成零。
- 多视角可能改善可见性，也可能引入冲突证据。像素坐标不同，不能不经对应/标定就当作同一个空间量。
- 机械臂的未标注部分仍可能影响遮挡和接触，不能视为天然无关背景。

连接 B 时只引用已有加权风险界：在同一敏感性加权分布下重新定义所有风险与条件均值，并满足参考动作、覆盖等条件，C 的风险界才可进入任务界。不新增另一套“保证成功”的长推导。

结尾过渡：

> 即使已有观测中的任务关系表达充分，单次观察仍可能无法区分运动趋势；生成计划之后的新变化也不在原信息中。下一节研究这些增量证据如何改变当前计划的执行。

## 3. D 的核心观点与结构

建议标题：

**D. 历史条件的动作块执行反馈**  
**History-Conditioned Feedback for Action-Chunk Execution**

核心观点：

> 反馈不是无条件地缩短重规划间隔，而是让新观测与因果历史对当前计划的剩余误差提供有效证据，并把方向和幅度合适的修正应用到正确执行时刻。

建议“总述 + 四个分述”。

### D.1 基于当前计划的增量反馈

段落职责：明确纠偏对象及新信息从哪里来。

基础策略生成动作块，当前槽位的基础动作 \(B\) 由原计划给定；纠偏器结合执行时可得的观测、计划上下文与因果历史，预测同一槽位的修正 \(r\)，形成 \(B+r\)。

必须分开两种信息：

- **新观测**：提供计划生成后已经发生的执行结果。
- **因果历史**：帮助区分当前画面近似相同、但动态趋势或先前事件不同的情况。

残差不是下一帧动作差分，也不是预测语义增量。所有动作先转换到 B 中一致的尺度。这里建立执行规则，不展开 GRU 层数和队列代码。

ACT 的频繁查询与时间集成本身也能利用新观测；A2C2 已有计划条件实时残差。D 的问题应是“历史增加什么证据、任务关系上下文提供什么作用”，而非泛称“首次把开环 ACT 变闭环”。[ACT](https://www.roboticsproceedings.org/rss19/p016.pdf)、[A2C2](https://arxiv.org/abs/2509.23224v1)。

### D.2 历史的增量价值与学习代价

段落职责：给出“历史何时真正值得加入”的判据。

沿用同一分布、同一目标动作 \(Y\)，基础计划误差为 \(E=Y-B\)。当前信息 \(\mathcal F_c\) 包含最新观测、本体信息和基础计划；\(\mathcal F_h\supseteq\mathcal F_c\) 额外包含因果历史。基础动作在两者下可测。

理想当前信息纠偏与历史纠偏分别为 \(m_c=\mathbb E[E\mid\mathcal F_c]\)、\(m_h=\mathbb E[E\mid\mathcal F_h]\)。历史的理想增益：

\[
\Delta_h=\mathbb E\|m_h-m_c\|^2.
\]

历史只有改变对当前计划误差的条件预测才产生严格增益。重复观测、无关帧以及已可由当前本体速度解释的动态，不应预设仍有额外历史收益。

实际编码信息 \(\mathcal U\subseteq\mathcal F_h\) 包含纠偏器全部输入，\(m_U=\mathbb E[E\mid\mathcal U]\)，实际修正 \(r\) 为 \(\mathcal U\)-可测。定义编码损失和拟合误差后，保留一个主要命题：

\[
R(B+r)-R(B+m_c)
=\epsilon_{\rm enc}+\epsilon_{\rm fit}-\Delta_h,
\]

其中 \(\epsilon_{\rm enc}=\mathbb E\|m_h-m_U\|^2\)，\(\epsilon_{\rm fit}=\mathbb E\|r-m_U\|^2\)。

因此，\(\Delta_h>\epsilon_{\rm enc}+\epsilon_{\rm fit}\) 是优于理想当前信息纠偏的充分且必要条件（在该恒等式设置下）。这不是实际 GRU 与实际 MLP 的排序公式；比较两个实际模型还要计入当前信息模型自身的拟合误差。

AIS 用于解释历史压缩的思想；Copycat 与 RAP 说明历史学习的困难。不把 GRU 架构当作充分状态证明，不把普通残差目标当作 RAP 式去捷径训练。[AIS](https://www.jmlr.org/papers/v23/20-1165.html)、[RAP](https://www.ecva.net/papers/eccv_2022/papers_ECCV/papers/136990386.pdf)。

### D.3 实际修正的方向、幅度与可验证收益

段落职责：从理想历史价值转到实际输出是否有效。

对任意实际残差，平方风险变化可直接写为：

\[
R(B)-R(B+r)=2\mathbb E\langle E,r\rangle-\mathbb E\|r\|^2.
\]

第一项衡量修正与基础误差的对齐，第二项体现修正幅度的代价。残差 RMS 大只说明改动较大，不能证明改得正确。零初始化和限幅可以约束行为，但不是风险下降的充分条件。

与前一命题的分工清楚：

- D.2 问“历史有没有潜在可利用价值，实际编码保留了多少”。
- D.3 问“最终输出是否与需要的修正方向一致”。

成功率联系直接回引 B 的性能差分关系。固定回放分布上的动作风险下降，不能替代修正后自主轨迹上的任务评估。现稿基于 \(Q^B\) 光滑 Hessian 的局部任务下降条件建议移至附录或删去：当前方法没有估计该量，而且接触切换处的光滑性需要额外条件。

### D.4 有效反馈的时序与整体边界

段落职责：让上述同一目标时刻的数学对象与实际控制一致。

需要说明采样时间、结果就绪时间、目标执行槽位和计划身份。迟到的槽位应丢弃，不能将其整体平移为后续动作；基础计划切换时也不能混用旧计划残差。

正文保持原则性描述；详细延迟和覆盖关系移到 Method。变动延迟时按每轮可用槽位区间检查重叠，不用一次平均延迟证明所有时刻连续覆盖。报告完整端到端延迟和有效修正覆盖率。

时间集成保留简短对照：它聚合同一执行时刻的多份预测，可以平滑噪声，也可能保留过时偏差；不等价于历史状态编码。现稿偏差/协方差推导可放附录，不把“为什么 ACT 时间集成不好”设为主要标题。[RTC](https://proceedings.neurips.cc/paper_files/paper/2025/file/300ccb2187dedd4edcc07f7e76d8e553-Paper-Conference.pdf)。

最后统一说明：只有固定示范时，残差标签来自示范访问状态下的基础预测误差，不能给自主偏离后的任意状态自动提供正确恢复指令。本文研究局部可学习改进，不主张全局恢复或 Lyapunov 收敛。

## 4. C、D 的连接不是简单串联模块

可以用一段统一解释：

> C 限制策略“依据什么作判断”，D 改善策略“根据执行中实际出现的证据如何更新判断”。前者侧重已有信息的可学习表示，后者侧重信息更新、历史辨识和计划条件修正。两者是否互补，需要交叉消融而非单独展示各自最好结果。

依据当前 Method 描述，基础策略的 query 上下文在基础计划更新时产生，并在快纠偏期间保留；快分支使用最新 RGB 和历史。因而不能描述成“每个快控制周期实时测量语义几何再视觉伺服”。这次规划没有重新审计训练/推理代码，正式写方法前应核对实际版本。

## 5. 文献定位与贡献表述

最重要的近邻是 A2C2，而不只是传统 Residual RL。A2C2 已具备最新观测、块内位置、基础特征、完整计划上下文及示范残差训练的组合。

建议把待验证贡献表述为：

> 在有限固定机器人示范下，研究语义引导的任务关系监督与历史条件的计划纠偏如何改善动作块策略的任务完成表现，并通过表示质量、历史增量信息和修正时序的受控分析解释其收益与边界。

不把“加法残差”“加入 GRU”“条件期望分解”本身写成理论创新。若没有历史或关系的独立证据，应收缩贡献范围，而不是依靠更强假设替代实验。

## 6. 最小但有判别力的实验规划

以下均为建议，未声称已有数据完成这些验证。

| 问题 | 建议对照 | 首要指标 |
|---|---|---|
| 语义和关系监督各自是否有效？ | RGB；RGB+语义；相同 query 结构但无关系监督；语义+关系监督 | 任务成功率、人工核验关系误差、目标槽位动作误差 |
| 有限示范是否体现数据效率？ | 相同轨迹级训练子集上的多个示范数量与随机种子 | 学习曲线；额外标注、预训练与参数预算 |
| 语义质量是否决定收益？ | 预测语义与人工审核语义；受控错误/遮挡 | 按可见性、关系类型分组，保留完整总体成功率 |
| 历史有无超出当前信息的价值？ | 同一冻结基础策略下当前帧纠偏、历史纠偏；匹配本体速度和计划输入 | 同分布残差风险、实际成功率、动作滞后 |
| 历史是否只是复制动作？ | 重复最近帧、打乱历史等诊断；另训练对应无历史对照 | 方向对齐、变化事件后的响应；不以分布外打乱单独证明因果作用 |
| 收益是否只是更高更新频率？ | 较频繁 ACT、ACT+时间集成、当前帧残差、历史残差 | 成功率、预算、端到端时延、预测年龄、平滑性 |
| C、D 是否互补？ | 关系监督开/关 × 历史反馈开/关的四组组合 | 同一测试分布上的效应及区间；不只比较最优种子 |
| 迟到结果是否削弱纠偏？ | 测量自然延迟；仿真/回放中受控延迟 | 有效槽位覆盖率、迟到丢弃率、错误计划匹配次数 |

优先完成同一冻结基础策略的当前帧纠偏与历史纠偏对照，避免把“换基础策略”和“加历史”混成一个因素。实机对照需使用预先约定的速度、关节限制和急停流程。

按 episode 划分训练/验证；邻近视频帧不是独立示范。不能将自主偏离状态与示范同时间索引的动作强配为专家恢复标签。回放风险和闭环成功率分开报告；统计区间按独立试验或适当的轨迹/位置分组计算。

## 7. 正式改写时的符号与篇幅控制

- 保留 A 的 \(s_t,o_t,u_t,\mathcal D,H_t,J\) 与 B 的 \(D,C,w,Y,B\) 含义；动作尺度矩阵 \(D\) 与小节 D 在排版中区分。
- 旧 C 用 \(C\) 表示控制上下文，和 B 的覆盖常数冲突，改为 \(\chi\)；无关外观不用 \(N\)，避免冲突示范数。
- 信息用 \(\mathcal F,\mathcal F_c,\mathcal F_h,\mathcal U\)；不重新引入已删除的任务输入 \(\eta\)。
- 关系、query、残差和语义状态增量分别命名，不能共用一个“delta”解释。
